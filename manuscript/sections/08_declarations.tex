\section*{Data and code availability}
The review package includes derived evidence, source manifests, executable notebooks, split records, configurations and result checksums. Original third-party products remain subject to provider terms. Identifying repository details are withheld from the anonymised manuscript and supplied separately to the editor. The standalone integrated experiment bundle is retained as historical evidence because some original intermediate inputs are unavailable; the supported notebook begins from the documented frozen derived-data boundary.

# Licensing status

This repository is the public data and code archive supporting the article
"Sensitivity-aware inspection prioritisation for archaeological landscapes: a
reproducible Taxila observatory".

| What | Licence | File |
|---|---|---|
| Analysis code and scripts | MIT | [`LICENSE`](LICENSE) |
| Derived data products | CC BY 4.0 | [`LICENSE-DATA`](LICENSE-DATA) |
| Manuscript text and figures | Not licensed for reuse here | subject to the publisher agreement |

"Derived data products" means the processed rasters, component-level score
tables, experiment outputs, simulation draw records and result tables generated
by this work.

Third-party datasets and cartographic materials retain their original provider
terms and are **not** covered by the licences above: Landsat Collection 2
(USGS/NASA), ESA WorldCover, Open-Meteo, NASA POWER, OpenStreetMap, Natural
Earth and geoBoundaries. The acquisition scripts and request manifests in this
repository allow those inputs to be re-acquired from their sources.
Bibliographic records do not transfer rights in the cited publications.

See [`manuscript/LICENSES_AND_ATTRIBUTION.md`](manuscript/LICENSES_AND_ATTRIBUTION.md) and the source manifests under [`data/Taxila_CHIP_Frozen_Evidence_Data/01_sources_and_manifests/`](data/Taxila_CHIP_Frozen_Evidence_Data/01_sources_and_manifests/) before copying, redistributing, or publishing any component.

# Name and scientific lineage

## Active project name

The active software and research-repository name is **Taxila Heritage
Observatory**. The GitHub repository slug is
`taxila-heritage-observatory`.

The Climate-contextual Heritage Inspection Prioritisation (CHIP) framework is a
methodological component of the study, not the repository name.

## Historical identifiers

Some checksum-locked evidence records contain earlier run IDs, source-bundle
names, inventory paths or embedded metadata that include `ProjectTaxila` or
`PreserveX`. These strings are retained only where changing them would falsify
the recorded acquisition or execution lineage, invalidate a checksum manifest,
or break an exact reference to an archived input bundle.

Historical identifiers must not be used for new branches, releases,
deliverables, documentation titles or repository locations. New generated
artifacts use the Taxila Heritage Observatory name.

## Naming convention

- GitHub and filesystem slug: `taxila-heritage-observatory`
- Reader-facing title: `Taxila Heritage Observatory`
- Python modules and notebooks: `snake_case` or a clear title using underscores
- Repository directories: lowercase `kebab-case` where the directory is not an
  immutable evidence path
- Dated audit records: ISO `YYYY-MM-DD`

Do not create numbered project copies such as `V9`. Use Git branches, tags and
release records for version control.
